# AstrBot 群聊主动回复管理

让机器人只在值得接话时主动加入群聊，减少复述、报时、强行吐槽和无意义回应。

插件不替换人格、记忆或模型。它在 QQ/OneBot 群聊中先拦截黑名单消息，再处理没有直接 @、引用或唤醒机器人的普通群消息：筛掉不该参与的内容，让模型判断是否值得接话。判断失败、超时或拿不准时默认保持沉默。

## 工作方式

```text
群消息
  ├─ 命中群黑名单或发送者账号黑名单
  │    → 阻止后续回复，包括直接 @、引用或唤醒
  ├─ 直接 @、引用或唤醒机器人
  │    → 交给 AstrBot 原有回复流程
  └─ 普通群消息
       → 检查群白名单、群黑名单和账号黑名单
       → 检查主动回复间隔
       → 按“参与判断概率”抽取
       → 有图片时由视觉模型生成图片描述
       → 模型判断现在是否值得接话
       → 达到“回复把握要求”后，使用当前会话人格生成回复
```

正文明确叫到“机器人称呼”时会跳过概率抽取，但仍会判断是否值得回复。普通消息即使没有称呼机器人，也可能按设置的概率触发。

## 与 AstrBot 自带功能的区别

| 功能 | AstrBot 自带群聊上下文 | 本插件 |
|---|---|---|
| 主要用途 | 为最终回答提供群聊背景 | 决定普通群消息是否值得主动接话 |
| 主动回复 | 内置功能抽中后直接进入回复流程 | 抽中后还要先判断是否值得回复 |
| 最近消息数 | 由 AstrBot 的群聊上下文设置控制 | 只由“参考最近消息数”控制 |
| 保存方式 | 由 AstrBot 管理 | 只保存在插件内存中，重启后清空 |
| 最终回复上下文 | 会提供给当前会话模型 | 不替换它，只额外提供接话判断所需的少量消息 |
| 人格和模型 | 使用当前会话配置 | 最终回复仍使用当前会话人格和模型 |
| @、引用、唤醒 | 正常回复 | 本插件不介入 |

使用本插件时应关闭 AstrBot 的“群聊上下文感知 → 主动回复”，但保留“群聊上下文感知”本身开启。否则两套主动回复可能重复触发。

## 配置

| 设置 | 默认值 | 作用 |
|---|---:|---|
| 参与判断概率（%） | 15 | 普通群消息有多大概率进入“要不要接话”的判断。0 表示普通消息不主动参与，100 表示每条都判断 |
| 回复把握要求（%） | 80 | 模型认为应该接话的把握达到多少才回复；越高越谨慎 |
| 判断使用的模型 | 跟随当前会话 | 只负责判断要不要接话；最终回复仍使用当前会话模型 |
| 识别图片使用的模型 | AstrBot 默认图片描述模型 | 只负责把图片转换成文字描述，不负责判断是否接话或生成最终回复 |
| 群白名单 | 空 | 群 ID 或完整 UMO；留空表示所有群 |
| 群黑名单 | 空 | 完全不响应这些群，包括直接 @、引用或唤醒；优先于群白名单 |
| 机器人称呼 | 空 | 例如 `Denia,达妮娅`；叫到这些名字时跳过概率抽取 |
| 账号黑名单 | 空 | 填写用户 QQ 号，机器人不会响应该用户 |
| 参考最近消息数 | 10 | 仅供判断要不要接话，不是 AstrBot 最终回复的会话上下文 |
| 主动回复间隔（秒） | 0 | 同一群两次主动回复的最短间隔；0 表示不限制 |
| 最长判断时间（秒） | 15 | 超时后保持沉默；最小 1 秒 |
| 查看群聊图片 | 关闭 | 允许模型查看普通群消息中的图片后再决定是否接话 |
| 最多查看图片数 | 1 | 每次判断最多提交多少张图片 |
| 记录判断结果 | 关闭 | 记录是否接话、把握程度和简短原因，不记录完整正文或图片地址 |

### 账号黑名单与 /sid

账号黑名单只检查消息发送者。填写用户 QQ 号后，无论该用户发送普通消息还是直接 @、引用或唤醒机器人，机器人都不会响应。这里不填昵称，也不填 `/sid` 返回的完整会话标识。

如果群里还有其他机器人，也可以填写它的 QQ 号，避免机器人之间互相响应。普通成员 @ 这个黑名单账号不会连带被屏蔽；是否响应仍按这位成员自己的账号及正常规则判断。

### 图片模型与判断模型

开启“查看群聊图片”后，视觉模型先把图片转换成文字描述；判断模型只读取文字、最近群消息和这段图片描述，不接收原图。确定需要回复后，最终回复仍由当前会话人格和模型生成。

视觉模型留空时尝试使用 AstrBot 的默认图片描述模型；两处都未配置或调用失败时，不把原图转交给判断模型，只按消息文字和“包含图片”这一事实判断。

### 模型维护与超时

不支持无限等待。模型维护期间，无限等待会占住当前群的判断任务。需要暂停时，请在 AstrBot 插件列表停用本插件；短暂故障、超时或非法返回会自动保持沉默。

## 图片与隐私

“查看群聊图片”默认关闭。打开后，即使没有人直接叫机器人，被抽中的普通群聊图片也会发送给所选视觉模型；判断模型只收到文字描述。如果最终回复，原图和描述还会交给当前会话模型生成回答。这可能产生费用，并会把图片发送给对应模型服务商。

## 安装

在 AstrBot WebUI 打开“插件 → 插件市场”，搜索：

```text
群聊主动回复管理
```

也可以搜索插件名 `astrbot_plugin_group_reply_gate`。如果插件市场尚未收录，在安装框输入仓库地址：

```text
https://github.com/kano0222/astrbot_plugin_group_reply_gate
```

安装后在插件列表启用，并按需配置群范围、模型和回复频率。

## 自动测试与发布

每次推送到 `main` 或提交 Pull Request 时，GitHub Actions 会运行 Ruff 和 pytest。推送与 `metadata.yaml` 版本一致的 `v*` 标签时，还会自动：

1. 运行全部检查；
2. 构建并校验可直接安装的 ZIP；
3. 上传 Actions 构建产物；
4. 创建或更新同名 GitHub Release。

`v1.0.0` 对应的压缩包名称为：

```text
astrbot_plugin_group_reply_gate-v1.0.0.zip
```

压缩包带有 `astrbot_plugin_group_reply_gate/` 顶层目录，解压到 `AstrBot/data/plugins` 即可。仓库中的测试、工作流、开发脚本和 `AGENTS.md` 不会进入发布包。

## 安全与失败处理

- 判断超时、报错或返回格式不正确：保持沉默。
- 当前群没有活动会话：保持沉默，不自动创建会话。
- 同一群已有判断正在执行：后续普通消息暂时忽略，不排队补答。
- 群之间的最近消息、回复间隔和执行状态相互隔离。
- 插件不建立用户数据库；运行状态重启后清空。
